✨ Lo que este sistema resuelve en juego:

  • No más pines tapándose entre sí: Puedes marcar que en el hexágono hay una Ruina (Slot 2) y que además los Aventureros están acampando allí (Slot 1) y que ronda un T-Rex (Slot 3).
  • Independencia total al hacer clic: Cada icono tiene su propio área de interacción, por lo que abrir la ficha del campamento o la de las ruinas es inmediato.
  • El número del hexágono queda despejado: El punto superior se ubica estratégicamente a 38% de la altura, dejando los primeros 25 px intactos para la etiqueta numérica.

⚙️ Modelo Matemático y Viabilidad de Implementación

El mapa de Chult mide 2816 × 2048 px. Cada hexágono tiene una altura de 128 px y una distancia horizontal entre columnas de 110.85 px. Las coordenadas se traducen directamente en porcentajes del lienzo para garantizar precisión matemática a cualquier resolución o nivel de zoom.

📐 1. Ecuaciones de Offset para Ranuras

Dado el centro del hexágono (cx, cy) en píxeles:

// Tríada Delta (Disposición recomendada) Slot 1 (Norte): x = cx y = cy - 14 px // (+24 px de margen al #1604) Slot 2 (Suroeste): x = cx - 29 px y = cy + 22 px Slot 3 (Sureste): x = cx + 29 px y = cy + 22 px

☁️ 2. Estructura de Datos en Firestore

100% compatible hacia atrás. Se agrega una propiedad slot opcional:

{ "id": "marker-179355", "hexId": "1604", "slot": 1, // 1 | 2 | 3 (default: 1) "icon": "ruins", "title": "Campamento Recto", "x": 62.4, // Porcentaje exacto del slot "y": 48.1, "updatedAt": "2026-11-01T..." }

🎯 3. Flujo al Crear o Mover Pines

Lógica automática sin fricción para jugadores y DM:

1. Al hacer clic en un hexágono: - Si está vacío: se asigna Ranura 1. - Si tiene 1 pin: se auto-asigna Ranura 2. - Si tiene 2 pines: se auto-asigna Ranura 3. 2. Arrastre magnético: - Al mover un pin cerca de un hex, se iluminan los 3 anclajes y hace "snap" al anclaje más cercano al cursor.
